## Principios
1. Toda empresa entra por **fase 0 sandbox simulada**, antes de recibir capacidades operativas.
2. Cada paso crea información útil, reutilizable en workspaces y en el futuro Digital Twin.
3. El estado de una empresa, de un servicio y de un conector es independiente.
4. Las aprobaciones de un humano y las validaciones técnicas son explícitas; nunca implícitas por una conversación.
5. No mezclar datos ficticios con datos reales ni afirmar que se ejecutó una acción que solo se simuló.
6. UX libre primero; después auditoría ligera de integración. No imponer contratos de backend prematuramente.
7. El mismo registro lógico se visualiza en chat, feed, Kanban, CRM, finanzas, timeline, grafo y Centro de Mando.
