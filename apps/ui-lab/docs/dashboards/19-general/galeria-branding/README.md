# Branding UX — sistema visual AgntiaPro

**Documento principal:** [Guía Maestra de Branding UX V2](./GUIA-MAESTRA-BRANDING-UX-V2.md).

Esta carpeta define la identidad y el lenguaje visual compartido para todas las superficies de AgntiaPro. La **landing actual** es la referencia editorial y el **Estudio Demo** es la referencia instrumental. La coherencia de marca no exige copiar layouts ni funcionalidades.

## Orden de lectura para agentes
1. [Guía Maestra V2](./GUIA-MAESTRA-BRANDING-UX-V2.md): tokens, tipografía, composición, componentes, responsive, motion cinematográfico y QA.
2. [Auditoría de branding y motion](./AUDITORIA-BRANDING-UX-Y-MOTION-2026-11-23.md): déficits y decisiones que originan la guía.
3. [Auditoría del Estudio Demo](../superficies-transversales/AUDITORIA-ESTUDIO-DEMO-VS-LANDING-2026-11-23.md): adaptación del diseño al software.
4. [Documentación legacy de landing](../../01-landing/legacy/README.md): fuentes históricas y precampañas, no instrucciones de ejecución vigentes.
5. [Copias de componentes reales de landing](../../01-landing/ejemplo-componentes-reales/README.md): snapshot para estudio, no componentes activos.
