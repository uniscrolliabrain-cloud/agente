# Chats de construcción

Conversaciones de trabajo con el agente, una por unidad de cambio. No son un chat general: cada hilo tiene proyecto, rama, intención y artefactos.

- Grupo: Construir · variante demo: `chats` · ruta visible: `~/chats`.
- Hoy muestra: composer, lista de conversaciones con proyecto y estado, y acciones simuladas.
- No implementado: streaming, adjuntos reales, diffs en línea, checkpoints, coste.
