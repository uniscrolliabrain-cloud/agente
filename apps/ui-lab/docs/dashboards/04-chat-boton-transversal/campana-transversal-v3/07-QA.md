## No ejecutado (declarado, no inventado)

- Cámara con permiso concedido y liberación de tracks reales: el Chromium del cloud no expone cámara. La limpieza está implementada (apagado, finalización y desmontaje) y se verificó el estado sin cámara.
- Dictado con `SpeechRecognition` y nota de voz con `MediaRecorder`: el navegador de QA no ofrece reconocimiento y el micrófono no está disponible; se verificaron los caminos de falta de soporte/permiso y sus mensajes.
- Lector de pantalla real, zoom 200 %, Safari, Firefox y dispositivos físicos.
- GitHub Actions: el artifact se generó y validó localmente con el mismo script del workflow; no se ejecutó el runner desde este entorno.
