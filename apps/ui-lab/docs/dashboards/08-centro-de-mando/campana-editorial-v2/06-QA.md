## Límites declarados

1. **Navegador**: el sandbox no puede lanzar Chromium local (falta `libnss3`, sin root). La batería
   se ejecutó con el navegador cloud del entorno contra el mismo build servido. `qa-cce.mjs` queda
   listo para ejecutarse en una máquina con Playwright instalado.
2. **Datos reales**: UI Lab bloquea `/api/company` (`safety.ts`). El estado poblado usa el router
   demo del navegador; vacío, error y carga se fuerzan con `?cce-state=`, un arnés de QA.
3. **Fuentes**: la vista editorial self-hostea Fraunces y Manrope (probado con terceros bloqueados),
   pero el laboratorio sigue importando Google Fonts desde `apps/web/src/index.css` y `lab.css`,
   preexistentes y fuera del alcance de esta campaña.
4. **No verificado**: lector de pantalla real, zoom 200%, vídeo de movimiento, ejecución del
   workflow de CI y despliegue. No se ha fusionado ni desplegado nada.
5. **Comparación visual con la landing**: se hizo con capturas a 1440; no sustituye la revisión
   del founder, que es la que aprueba el gate.
