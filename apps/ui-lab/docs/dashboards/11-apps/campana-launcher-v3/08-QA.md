## Fallos encontrados y corregidos durante el QA

1. Foco de retorno apuntaba a un nodo desmontado → se guarda el nombre y se busca el icono montado.
2. El primer Escape se perdía (input de búsqueda y cambio de pantalla) → manejador propio en cada
   capa modal; 3/3 y 2/2 al primer intento.
3. La selección táctil se cancelaba por burbujeo del clic → el contenedor ignora clics en controles.
4. Scroll de 26 px por el badge del laboratorio → encaje con `:has()`.
5. Objetivos táctiles de 38–40 px → 40–44 px.
