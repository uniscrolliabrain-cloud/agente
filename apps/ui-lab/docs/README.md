# UI Lab — documentación de trabajo

Este directorio es la **ubicación canónica** de la documentación asociada a UI Lab y a la simulación empresarial de AgntiaPro. Está versionado en `main`, junto al código del laboratorio.

## Entradas

- [**agntia-demo/**](./agntia-demo/) — Kickoffs originales completos, instrucciones literales del founder, plantillas, datos sintéticos y campaña de unificación de tenants.
- [**Documentación de UI Lab**](./) — Guías y documentación general del laboratorio de interfaces: `AGENT-DEMO-WORKFLOW.md`, `AUTO-PREVIEW.md`, `FULL-APP-CLONE.md`, `IMPLEMENTATION.md`.

## Principios

- Los documentos originales del founder y del CEO se conservan íntegros, sin reescritura.
- El mensaje comercial de la landing sigue siendo la puerta de entrada y no se redefine por añadir capacidades.
- Los planes y datasets sintéticos se distinguen del código implementado y de datos reales.
- Los documentos de UI Lab pertenecen a `apps/ui-lab/docs/`; no crear árboles paralelos en `docs/agntia-demo/` o `docs/ui-lab/`.
- No mezclar campañas documentales con despliegues, modificaciones del kernel o migraciones de producción.
