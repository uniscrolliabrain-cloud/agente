# Handoff completo para las 7 IAs de la Campaña 2 (Multiusuario)

Cada handoff es **autocontenido**. Una IA que reciba solo su bloque + el repo en disco + el protocolo TypeScript v2 puede aplicar su fase sin leer el resto del chat ni el repo entero. Cada bloque declara: contexto mínimo, ficheros a leer, ficheros a inspeccionar con `Select-String`, ficheros a no tocar, patchsets, verificación, misses esperados y criterio de cierre.

**Regla común a las 7 IAs:** la fuente de verdad es el disco. El Repomix y el maestro son referencia histórica. Si un ancla no coincide exactamente 1×, se aborta el patchset y se anota el miss. No se declara `PASS` sin haber ejecutado y visto el output.
