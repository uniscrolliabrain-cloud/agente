# Proveedores y transferencias

| Proveedor | Evidencia de código | DPA, región y transferencia |
|---|---|---|
| Vercel y Fly | Deploy estático y servidor/worker | Pendiente por proyecto |
| Postgres/Neon | Config y scripts de DB; PGlite local | Instancia, región y backups pendientes |
| Google y GitHub | Login; Google Workspace y Fonts | Diferenciar identidad, recursos y APIs de datos |
| Meta y Vapi | Rutas WhatsApp y telefonía | Confirmar cuentas, procesamiento y grabación |
| Google Gemini, OpenAI compatibles, Anthropic | Config y runtime por tenant | Validar configuración activa, retención y controles |
| Anam y ElevenLabs | Scaffold de rama e informe histórico | Confirmar vigencia, sandbox y contratos |
| Resend | Config de correo | Confirmar remitente, uso y retención |
| Automatización del navegador | Playwright worker, accede a servicios según operación | Identificar destinos, perfiles persistentes y tratamiento por contrato |

Inventario técnico. Los roles jurídicos, DPA/SCC, subencargados reales y la localización de datos requieren evidencia contractual y configuración de cada tenant y proveedor.
