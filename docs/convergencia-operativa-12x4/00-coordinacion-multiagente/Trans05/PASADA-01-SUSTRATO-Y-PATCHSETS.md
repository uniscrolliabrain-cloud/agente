## 3 Diseño y patchsets
P01 inventario y baseline: congelar HEAD y blobs, mapear callers de context/graph/slow, thread admission Trans02 P04, card ontology, persona/section catalog. No tocar kernel generic ni legacy. 
P02 anchors: candidato annotation sidecar versionada sobre CognitiveRecord card, no nuevo tipo record hasta auditoría ontology. 
```ts
type AnchorKind="axiom"|"intent"|"invariant"|"finding"|"distinction"|"contradiction"|"hypothesis"|"decision"|"question"|"synthesis"|"correction";
type AnchorAnnotation={schemaVersion:"1";threadId:string;cardId:string;cardRevision:number;kind:AnchorKind;authority:"user_stated"|"model_proposed"|"authorized_source";state:"active"|"disputed"|"superseded";sourceRefs:readonly {id:string;revision:number}[]};
```
Candidate not ABI: Zod strict, exact source refs via existing cognitiveRefSchema, thread scope resolved server-side, not user-supplied. Authority user_stated means conversational premise, not factual proof or permission. Revision immutable, CAS head, corrections supersede only explicit scope, no delete. 
P03 graph layers logical views not six databases. Evidence, semantic, anchors, models, axioms, metacognition; edges supports/contradicts/refines/supersedes/depends_on/illustrates proposed mapping existing edge schema. Fix exact endpoint revision and edge/node budget before use. Cycle bounded, no leakage. 
P04 cognitive skills catalog versioned declarative, developer approved templates, typed input/output, allowed source kinds, cost budget, trigger and stop condition. First principles, perspective, abstraction, concretization, contradiction, drift, causal, counterfactual, synthesis, strategy, meta review, feedback. Six-frame composed skill. No arbitrary code from tenant cards, no operational authority. Output proposals only, not private chain-of-thought storage.
P05 selector deterministic eligibility then score, JEV optional classification. Triggers explicit correction, topic shift, unresolved contradiction, budget threshold, periodic checkpoint; coalesce by thread revision, bounded jobs, no recursive self-trigger. Separate persistent salience from query relevance, uncertainty from truth. 
P06 Slow longitudinal consumer from authenticated immutable intent journal Trans02 P04, not mutable threads or existing receipt-only bridge. Stable key tenant/actor/thread/message revision/skill version, watermark and CAS; stale output rebase/recompute, never overwrite newer corrections. Async no Fast wait. 
P07 JEV existing classifier port, schema validate proposed anchor type/relations and source refs; fallback deterministic no semantic invention. No new provider calls on Fast. 
P08 living brief ~120 words, projection of authorized anchors and sources, not recursive summary. Store refs + watermark + revision, regenerate on correction/revoke, no stale unauthorized text. Budget soft word target plus hard token/byte cap. 
P09 attention: add thread-scoped active anchor retrieval before latest candidate truncation; merge dedup exact revisions, reserved budget for active principles and current question, recent/history/narrative separate quotas, no forced inclusion denied.
