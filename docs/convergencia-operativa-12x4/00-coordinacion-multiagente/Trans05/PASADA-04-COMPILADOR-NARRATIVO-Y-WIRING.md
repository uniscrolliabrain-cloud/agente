## P10 detailed implementation candidates

LLM brief is proposal origin, not external evidence. No downloading protected media or assuming public access grants reuse. Batch STT port optional, unavailable by default; user-supplied authorized transcript works without provider. 
P10.2 segmentation: separate provenance index over immutable normalized text, record normalization version, original page or time range when provided, char offsets defined as UTF16 code units, segment digest; no fabricated timestamp. Keep RAG chunkText unchanged. Candidate:
```ts
type Segment={start:number;end:number;text:string};
function segmentText(source:string,max=2400,overlap=200):Segment[]{
 if(!Number.isSafeInteger(max)||!Number.isSafeInteger(overlap)||max<2||overlap<0||overlap>=max-1)throw Error("SEGMENT_CONFIG");
 const out:Segment[]=[];let start=0;
 while(start<source.length){
  let end=Math.min(source.length,start+max);
  if(end<source.length&&/[\uD800-\uDBFF]/u.test(source[end-1]))end--;
  if(end<=start||out.length>=10000)throw Error("SEGMENT_BUDGET");
  out.push({start,end,text:source.slice(start,end)});
  if(end===source.length)break;
  let next=Math.max(start+1,end-overlap);
  if(/[\uDC00-\uDFFF]/u.test(source[next]))next--;
  if(next<=start)next=end;
  start=next;
 }return out;
}
```
Candidate pure function; production semantic boundaries and source mapping tests needed. No silently dropping short segments. Batch checkpoints stable segment digest, retry idempotent, no whole book in prompt.
