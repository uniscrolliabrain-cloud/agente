# P10 — ampliación founder: compilador de skills narrativas
Vinculante como alcance conceptual de Trans05; sustituye P10 limitado a matching. Infraestructura para construir cards mediante LLM o transcripciones de libros, expertos de YouTube y vídeos de actores de la empresa. No implica importar fuentes sin permiso ni implementar ahora.
## Pipeline
1. Ingesta mediante puertos existentes de documentos/RAG/media/transcripción; fuente autorizada, tenant, sección, actor, idioma, licencia/consentimiento, hash y revisión. No scraping indiscriminado ni asumir derecho a reutilizar vídeos/libros. 
2. Segmentación con páginas o timestamps, contexto y referencias estables; preservar fuente original autorizada.
3. Slow extrae patrones comunicativos: historias, analogías, argumentos, explicaciones, objeciones, preguntas, protocolos, ejemplos y distinciones. JEV propone clasificación, similitud, duplicados y contradicciones. Separar hechos de opiniones y técnicas generales de afirmaciones particulares de empresa.
4. Compilar candidatos estructurados; LLM también genera desde briefing o entrevista guiada sin fuente externa, marcado como propuesta. No inventar evidencias.
5. Validación determinista de schema, ACL, provenance, claims, vigencia, sección y presupuesto. Revisión humana autorizada antes de publicar repertorio empresarial. No auto publicación de texto externo ni instrucciones de ejecución.
6. Versionar y publicar en cards existentes si compatible; índice semántico y triggers tipados. Fast selecciona solo publicadas/autorizadas, adapta expresión, no repite literal ni atribuye vivencias falsas. Revocación de fuente invalida derivados; conservar audit trail permitido.
## Contrato candidato
NarrativeSkillDraft: id, revision, tenantId, sectionRef, roleRefs, sourceRefs (document/page or media/time interval), origin (llm_proposal|source_extraction|human_authored), communicativeIntent, semanticTriggers, runtimePredicates (closed typed state), mandatoryPoints, optionalExamples, prohibitedClaims, factualRefs, locale, tone, expiry, reviewStatus, approvedBy. Source content untrusted, no prompt authority. Runtime predicates evaluate authorized receipts; accepted != delivered. Separate reusable technique from tenant-specific facts; no cross-tenant promotion without explicit license and approval.
## P10 subpatchsets
P10.1 source registry and existing ingestion adapter audit; P10.2 segmentation/provenance; P10.3 Slow extraction and JEV classification; P10.4 draft schema, review and publication; P10.5 semantic/runtime matching and Fast composition; P10.6 lifecycle/revocation and telemetry. No new provider or duplicate RAG by default. Dependencies Trans02 context integrity, Trans03 media/receipt ports, Trans04 observability. 
## Evaluation
Synthetic approved menu and sales interview; extract cards, compare source fidelity and expert review, test conflicting prices, outdated menu, prompt injection, wrong tenant, revoked video, duplicate transcript, hallucinated claim, runtime unknown. Measure extraction precision, approval/edit rate, match precision, factual fidelity, user usefulness, latency/cost. Tuning versioned, no automatic policy mutation. No source media or tests processed in this turn; design only.
