### Candidate budget algorithm
```ts
type Item={id:string;revision:number;text:string;priority:number;group:"anchor"|"brief"|"narrative"|"general"};
function pack(items:readonly Item[],limit:number,quotas:Record<Item["group"],number>){
 const used={anchor:0,brief:0,narrative:0,general:0};let total=0;
 const seen=new Set<string>();const out:Item[]=[];
 for(const x of [...items].sort((a,b)=>b.priority-a.priority||a.id.localeCompare(b.id)||a.revision-b.revision)){
  const key=JSON.stringify([x.id,x.revision]),n=Buffer.byteLength(x.text,"utf8");
  if(seen.has(key)||n+total>limit||n+used[x.group]>quotas[x.group])continue;
  seen.add(key);used[x.group]+=n;total+=n;out.push(x);
 }return {out,total,used};
}
```

Metrics: anchor recall = eligible required anchors retrieved / eligible required anchors; fidelity = correct current propositions expressed / required propositions; stale leakage = superseded or revoked claims emitted / probes; drift = off-goal responses / evaluated responses; narrative precision = relevant activations / all activations; false activation rate = negative probes activated / negative probes. Zero denominator N/A not perfect. Separate deterministic retrieval assertions from model response rubric; blinded human or independent evaluator with fixed gold, report disagreements. Proposed gates recall >=.95 at 100k and >=.90 at 500k, fidelity >=.90, narrative precision >=.90, zero cross-scope/revoked leaks and false confirmed claims in fixtures, no unbounded jobs, no regression Fast p95 >10% vs baseline under same load; thresholds provisional, sample counts and confidence intervals reported.
